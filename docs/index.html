Overview

External overlay for Roblox on Linux via Sober. Reads memory, draws a menu through the compositor, executes Luau in-process through a callgate.

What it is

The external is two binaries: an updater called install and the actual overlay called external. The updater hits the CDN, verifies the manifest against a pinned public key, swaps binaries atomically, and launches the overlay.

The overlay itself opens a GLFW window with a transparent framebuffer, matches Sober's geometry, and stays above it. Input outside your menu windows passes through to Roblox via XShape. Memory reads and writes go through /proc/<pid>/mem.

Requirements

  • Linux with X11 or Wayland (XWayland works)
  • Sober flatpak installed and launched at least once
  • A compositor that respects transparent framebuffers. Tested on Mutter, KWin, and Hyprland.
  • Around 40 MB of disk for the install directory

Quick start

  1. Download the installer from your dashboard after purchase.
  2. Make it executable: chmod +x install
  3. Run it: ./install
  4. Paste your license key when asked. The installer verifies, writes files to ~/.local/share/nyx, and launches the overlay.
  5. Start Sober. The overlay attaches once it finds the process.
  6. Press Insert to toggle the menu.

The install directory holds a small config, saved bookmarks and scripts, and the swap slot the updater uses. Deleting it uninstalls cleanly.

Scripting

The overlay ships with a full Luau VM. It reads Roblox state, draws overlays, binds keys, and talks back to Roblox through a callgate. Read the full API reference for every function.

-- example: print your character position every 3 seconds
task.spawn(function()
    while true do
        local c = game.Players.LocalPlayer.Character
        if c and c.HumanoidRootPart then
            print(c.HumanoidRootPart.Position)
        end
        task.wait(3)
    end
end)

Scripts live in ~/.config/nyx/scripts. The Scripts tab lists every .lua and .luau in there, plus lets you save the current editor buffer.

Troubleshooting

Menu shows solid black where it should be transparent

Your compositor is not compositing the overlay. On KDE the fix is usually one of the WM hints the overlay already sets. If it still happens, disable "Block compositing" as a window rule for the Nyx window, and confirm compositing is enabled globally in System Settings.

Cannot click Roblox while the overlay is up

On Hyprland the overlay uses XShape to pass clicks through everywhere except inside its own menu windows. If clicks are still eaten, update to a recent Hyprland build. As a fallback add this to ~/.config/hypr/hyprland.conf:

windowrulev2 = nofocus, class:(Nyx External)

Overlay says "waiting for Sober"

Sober is not running, or the flatpak is under a different name. Launch Sober first, then start the overlay.
