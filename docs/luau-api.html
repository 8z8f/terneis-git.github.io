Signals

Signal:Connect(fn) or :connect(fn) or :Once(fn) returns a Connection.

Signal:Wait([timeout]) yields the calling coroutine until the signal fires. Returns the fire's arguments, or nil if the timeout hits first.

Connection:Disconnect() / :disconnect(), .Connected is a boolean.

Handlers run in their own coroutine each fire, so task.wait, :WaitForChild, and other yielding calls work inside a Connect callback. Handler errors print [error] <msg> to the console. Other handlers still fire.

UserInputService

Access via game:GetService("UserInputService").

Methods: :IsKeyDown(kc), :IsMouseButtonPressed(b), :GetMouseLocation() returns Vector2.

Signals: .InputBegan(io, gp), .InputEnded(io, gp), .InputChanged (reserved), .MouseButton1Down/Up, .MouseButton2Down/Up.

inputObject: { UserInputType, KeyCode = {Value, Name, EnumType}, Position = Vector3(mx, my, 0), Delta = Vector3(0, 0, 0) }.

Keybinds

Thin wrappers around the input pipeline. Skip hand-rolling an InputBegan handler for simple hotkeys.

keybind(key, fn [, mode]) binds a single key. key can be a string name ("F", "LeftShift", case-insensitive for letters), an Enum.KeyCode.X, or a raw numeric code. mode is "down" (default), "up", or "both". The callback gets one bool argument (true=pressed, false=released). Returns a handle with :Disconnect().

keybind_combo(keys, fn [, mode]) is a chord binding. keys is a list; the last key is the trigger and every earlier key must be held when it fires.

local hk = keybind("F", function(down)
    print("F is now", down and "down" or "up")
end, "both")

keybind_combo({Enum.KeyCode.LeftShift, "R"}, function()
    print("Shift+R pressed")
end)

hk:Disconnect()

Bindings are cleared automatically when the VM stops or reloads.

Mouse

Access via LocalPlayer:GetMouse().

Fields: .X, .Y (X11 root coords), .Hit (CFrame at pointer target, camera raycast 5000 studs, identity rotation), .Target (Instance under pointer, nil if nothing).

Signals: .Move, .Button1Down, .Button1Up, .Button2Down, .Button2Up.

.Hit and .Target reuse workspace:Raycast, so they share the OOBB limits. MeshPart triangles and Terrain will not register.

HttpService

Access via game:GetService("HttpService"). Runs outside Roblox's sandbox, so HttpEnabled does not apply.

:GetAsync(url)Blocking GET, returns the body string
:PostAsync(url, body, ct?)Blocking POST, default content-type application/json
:JSONEncode(t)Table to JSON string
:JSONDecode(s)JSON to table, raises on parse error
:GenerateGUID(wrap?)GUID string, wrap=false drops braces

Blocks the render thread until each request finishes. libcurl timeout is 15 seconds.

BindableEvent / BindableFunction

Instance.new("BindableEvent") and Instance.new("BindableFunction") both work.

BindableEvent: .Event (Signal), :Fire(...) invokes every connected handler and resumes every waiter, :Destroy() is a no-op.

local be = Instance.new("BindableEvent")
be.Event:Connect(function(a, b) print("got:", a, b) end)
be:Fire("hello", 42)

BindableFunction: .OnInvoke (assign a function), :Invoke(...) calls it synchronously and returns its return values.

local bf = Instance.new("BindableFunction")
bf.OnInvoke = function(a, b) return a + b end
print(bf:Invoke(3, 4))  -- 7

TweenService

game:GetService("TweenService"):Create(instance, TweenInfo.new(...), {prop = target}) returns a Tween. It runs on the tick pump and writes back to the instance every frame.

local Tween = game:GetService("TweenService")
local part  = workspace.SomePart
local info  = TweenInfo.new(2, Enum.EasingStyle.Sine, Enum.EasingDirection.Out)
local tw    = Tween:Create(part, info, {
    CFrame       = part.CFrame * CFrame.new(0, 10, 0),
    Transparency = 1,
    Color        = Color3.fromRGB(255, 0, 0),
})
tw.Completed:Connect(function(state) print("done:", state) end)
tw:Play()

TweenInfo.new(time, easingStyle?, easingDirection?, repeatCount?, reverses?, delayTime?). Defaults match Roblox: time=1, Quad, Out, 0, false, 0. Style and direction accept Enum items or raw ints.

Tween: :Play, :Cancel, :Pause. .Completed Signal, .PlaybackState string.

Supported property kinds: number, Vector2, Vector3, Color3, CFrame. CFrame lerps component-wise (position accurate, rotation close for small deltas). Unsupported kinds are silently ignored at Create time.

Easing styles: Linear, Sine, Quad, Cubic, Quart, Quint, Back, Circular, Exponential. Each with In / Out / InOut.

Windows

Window.new(titleOrTable) returns a movable, resizable ImGui window backed by a persistent Lua object. Widgets stay alive until :Remove(). Callbacks run in coroutines, so yielding calls work inside them.

local win = Window.new({
    Title    = "My Menu",
    Position = Vector2.new(120, 120),
    Size     = Vector2.new(320, 400),
})

win:Label("Aimbot")
win:Toggle("Enabled", false, function(on) print("aim:", on) end)
win:Slider("FOV", 10, 500, 150, function(v) print("fov:", v) end)
win:Combo("Target part", {"Head","Torso","Feet"}, function(idx, name)
    print("target:", name)
end)
win:Separator()
win:TextInput("Name", "player123", function(s) print("name:", s) end)
win:Button("Reset", function() print("reset!") end)
win:Image("/home/yeto/Pictures/icon.png", Vector2.new(64, 64))
:Button(text, cb?)cb() on click
:Slider(text, min, max, default?, cb?)cb(value) on drag
:Toggle(text, default?, cb?) / :Checkboxcb(state) on click
:Label(text) / :Textplain text
:TextInput(text, default?, cb?) / :Inputcb(string) on Enter
:Combo(text, items[], cb?) / :Dropdowncb(index, name) on selection
:Separator()horizontal rule
:SameLine()keep next widget on the same row
:Image(path, size?)loads PNG or JPEG from disk, size is Vector2

Widget properties: .Text / .Label (mutable), .Value (number for Slider, bool for Toggle, string for TextInput, 1-based index for Combo), :Remove() / :Destroy().

Window properties: .Title, .Visible, .Position, .Size, :Remove(). Users can drag and resize; changes flow back into .Position and .Size.

Drawing

Drawing.new(kind) returns an object that blits onto ImGui's foreground draw list every frame. Screen coords, over everything, no game overlay interaction.

Kinds: "Line", "Square", "Circle", "Text", "Triangle", "Quad", "Image".

Common properties: Visible (default false), ZIndex, Color, Transparency (0 = fully transparent, 1 = opaque, exploit convention), Thickness, Filled. Methods: :Remove() / :Destroy().

Kind Properties
LineFrom, To (Vector2), Thickness
SquarePosition (top-left), Size, Rounding, Filled, Thickness
CirclePosition (center), Radius, NumSides, Rotation, Filled, Thickness
TextPosition, Text, Size, Font, Center, Outline, OutlineColor, TextBounds (read-only)
TrianglePointA, PointB, PointC, Filled, Thickness
QuadPointA, PointB, PointC, PointD, Filled, Thickness
ImagePosition, Size, Data (file path), Rounding, Rotation, ImageSize (read-only), Loaded (read-only)
 
local dot = Drawing.new("Circle")
dot.Position = Vector2.new(400, 300)
dot.Radius   = 6
dot.Color    = Color3.fromRGB(255, 100, 100)
dot.Filled   = true
dot.Visible  = true

local label = Drawing.new("Text")
label.Position     = Vector2.new(400, 320)
label.Text         = "hello"
label.Center       = true
label.Outline      = true
label.Color        = Color3.fromRGB(255, 255, 255)
label.OutlineColor = Color3.fromRGB(0, 0, 0)
label.Visible      = true

Drawing.clear()  -- remove all

Screen coords are the same as UIS :GetMouseLocation(), i.e. X11 root coords.

Raycasting

workspace:Raycast(originV3, directionV3, params?) returns a RaycastResult or nil.

RaycastParams is a plain table from RaycastParams.new(): FilterDescendantsInstances (Instance[]), FilterType ("Include" / "Exclude" or Enum), IgnoreWater (accepted, not enforced).

RaycastResult is a plain table: Position, Normal, Distance, Instance, Material (placeholder "Enum.Material.Plastic").

Limits: OOBB approximation, walks up to 8192 BaseParts, no CollisionGroup, no MeshPart triangles, no Terrain voxels.
