Installing

Five minutes from zero to menu.

Install Sober

Sober is the Wine-based Roblox flatpak. If you already run Roblox on Linux you probably have it.

flatpak install flathub org.vinegarhq.Sober
flatpak run org.vinegarhq.Sober

Log in once, join any game, close it. The overlay looks for the running process by class name, so Sober needs to have opened cleanly at least once.

Run the installer

After purchase you get a link to the install binary and your license key. Drop the binary anywhere writable, mark it executable, and run:

chmod +x install
./install

The installer verifies its own signature against a pinned public key, prompts for your license, and writes the payload to ~/.local/share/nyx. It never asks for sudo.

First launch

The installer launches the overlay when it finishes. If Sober is already running the menu attaches within a second. If not, launch Sober now, then rerun:

~/.local/share/nyx/external

Press Insert to toggle the menu. If you want a different toggle key, open Settings → Keybinds.

Updating

Every time you run the launcher it hits the manifest, checks the signed version, and swaps the binary atomically if a newer one is out. Nothing else to do.

You can force a check by running ./install again.

Uninstall

Delete the install directory:

rm -rf ~/.local/share/nyx ~/.config/nyx

The first path holds the binaries and swap slot. The second holds configs, saved scripts, and bookmarks. Nothing else on your system is touched.
